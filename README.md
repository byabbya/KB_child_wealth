# KB 우리 아이 자산관리

KB스타뱅킹 내부 메뉴를 가정한 미성년자 장기 자산관리 서비스 시연본입니다.

> 부모가 KB스타뱅킹에서 자녀 명의로 보유한 KB국민은행 예·적금 계좌와 KB증권 투자계좌를 한 번에 확인하고, 자녀의 투자 기간과 보호자의 자산·투자방식 선호 순위에 맞춰 KB금융그룹 금융상품을 중심으로 장기 포트폴리오를 추천받는 미성년자 자산관리 서비스

시연 환경에서는 로그인, 실제 자녀정보 조회, 계좌 연결, 주문을 수행하지 않습니다. 한 명의 고정 샘플 자녀와 샘플 KB 보유자산만 사용합니다.

## 핵심 구조

1. 사용자가 `적금·예금·주식·채권`과 `ETF·개별종목·미주·국내종목`의 순위를 정합니다.
2. Gemini가 사용자 조건과 기준일이 있는 시장·뉴스·KB 리서치 샘플을 병렬 분석합니다.
3. 두 분석을 결합해 8개 자산군의 목표 비중과 근거만 제안합니다.
4. 정책 검증기가 비중 합계, 투자기간 상한, 기준안 대비 ±5%p와 시장 근거를 검사하고 보정합니다.
5. 검증된 최종 비중에 기존 KB 상품 정책을 통과한 상품을 매칭합니다.
6. 도넛, 상품 명세서와 리밸런싱에는 같은 최종 비중을 적용하고 금액·세금·비용은 규칙 엔진이 다시 계산합니다.

AI는 세법이나 상품 조건을 만들어내지 않습니다. 규칙 엔진이 계산한 사실만 참고해 포트폴리오를 구성하고 설명합니다.

## 로컬 실행과 Gemini

```bash
npm install
npm run dev
```

로컬과 공개 배포 모두 서버 측 `/api/portfolio-advice`가 Google Gemini를 호출합니다. `.env.example`을 참고해 Git에 포함되지 않는 `.env.local`에 `GEMINI_API_KEY`를 입력할 수 있으며, `GEMINI_MODEL`의 기본값은 `gemini-2.5-flash`입니다. 공개 배포에서는 같은 키를 Sites 서버 비밀값으로 등록합니다.

키가 없으면 화면에 `Gemini 연결 실패·규칙 기반 추천`을 표시하며 AI가 실행된 것처럼 표현하지 않습니다. API 키는 브라우저, 응답, 로그 또는 저장소에 두지 않습니다.

## 포트폴리오 화면

- 현재 포트폴리오와 AI 추천 포트폴리오를 같은 색상 체계의 도넛 두 개로 비교합니다.
- 명세서 한 행에서 현재 비중·금액, 추천 비중·금액, 차이, KB 상품, 조치와 위험등급을 확인합니다.
- 상세 행을 펼치면 AI 추천 이유, 금리·수익 가정, 우대조건, 세금·비용, 만기, 예금자보호, 기준일과 출처를 확인할 수 있습니다.
- AI 분석 전 또는 실패 시에는 규칙 기준안을 동일한 화면 구조로 표시합니다.

## 데이터와 규칙 갱신

- `data/sample_scenario.json`: 고정 샘플 자녀, KB 보유자산, 최근 10년 증여내역
- `data/kb_bank_products.csv`: KB국민은행 상품과 과세·비용·정책 분류
- `data/kb_securities_assets.csv`: KB증권 거래 자산과 과세·비용·정책 분류
- `data/kb_product_policies.yaml`: Young Youth 통장·적금 등 자녀 상품 조건
- `data/gift_tax_rules.yaml`: 증여재산공제, 합산, 누진세율, 신고기한
- `data/investment_tax_rules.yaml`: 이자, 국내외 주식·ETF 과세 분류
- `data/fee_assumptions.yaml`: 증권 수수료, 환전, 상품보수 가정
- `data/product_sources.json`: 공식 출처
- `data/market_snapshot.json`: 기준일이 있는 시장지표·뉴스·KB 리서치 형식 샘플

YAML 파일은 별도 파서 의존성을 줄이기 위해 JSON 호환 YAML 문법으로 저장합니다. 모든 규칙과 상품정보는 기준일·마지막 확인일·출처를 가지며, 변경 가능한 상품명·금리·한도를 화면 코드에 하드코딩하지 않습니다.

## 증여세 시뮬레이션

고정 시나리오는 최근 10년 동일 부모·배우자 그룹 증여액 1,800만 원과 추가 현금 증여 500만 원을 사용합니다.

- 추가 전 잔여 증여재산공제: 200만 원
- 10년 합계: 2,300만 원
- 추정 과세표준: 300만 원
- 기본 산출세액: 30만 원
- 기한 내 신고세액공제 3% 가정 후: 29만 1천 원

흔히 말하는 “미성년자 2천만 원 비과세”가 아니라 직계존속 증여재산공제 적용 결과로 설명합니다. 부담부증여, 비상장주식 평가, 해외 증여, 명의신탁, 세대생략 할증 등은 자동 계산하지 않습니다.

## KB국민은행 기대효과

- 자녀 입출금통장 개설 이후 예·적금, 펀드, KB증권 투자계좌의 장기관리로 관계 확장
- 부모와 자녀가 함께 자산·증여·세후성과를 확인하는 금융교육 경험 제공
- 자녀 성장 단계에 따른 KB국민은행 상품과 KB증권 투자서비스의 적합한 연결
- 예·적금 만기자금이 목표 부족 자산으로 재배분되도록 지원
- 단순 판매가 아닌 목표·선호·기간·세후비용에 근거한 상품 선택
- 자녀 성년 이후에도 이어지는 장기 고객관계 형성

## 제한

모든 링크는 Mock이며 실제 가입·주문을 실행하지 않습니다. 결과는 샘플 데이터 기반 추정치로 금융자문, 세무신고 또는 투자판단용 확정 수치가 아닙니다. 실제 이용 전 최신 상품설명서·약관·법령과 전문가 의견을 확인해야 합니다.
