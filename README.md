# KB 우리 아이 자산관리

KB국민은행 공모전 제출용으로 만든 반응형 웹 MVP입니다.

> 부모가 KB스타뱅킹에서 자녀 명의로 보유한 KB국민은행 예·적금 계좌와 KB증권 투자계좌를 한 번에 확인하고, 자녀의 투자 기간과 보호자의 위험 성향에 맞춰 KB금융그룹의 금융상품을 중심으로 장기 포트폴리오를 추천받는 미성년자 자산관리 서비스

## 데모에서 할 수 있는 일

- 자녀 명의의 KB국민은행 계좌와 동의된 KB증권 보유자산 통합 조회
- 최근 10년 증여 내역 등록과 브라우저 내 저장
- 4문항 보호자 위험 성향 및 투자기간에 따른 목표 자산배분
- 현재 보유 KB 상품 우선 유지, 검증된 KB 상품 후보 매칭
- 신규 입금·만기자금·KB증권 예수금을 우선하는 리밸런싱
- 중도해지 손실이 큰 예·적금 유지와 만기 후 재배분 예약
- KB 적금 대비 포트폴리오 세후 성과 점검
- 보호자 승인과 KB스타뱅킹·KB증권 M-able Mock 이동

## 실행

```bash
npm install
npm run dev
```

검증은 `npm test`, 배포 빌드는 `npm run build`로 실행합니다. 입력값, 증여 내역, KB증권 연결 및 승인 상태는 `kb-child-portfolio-demo:v1` 키로 브라우저에만 저장됩니다.

## 데이터 갱신

상품·금리·보유자산·출처·세금 규칙은 각각 다음 파일에서 관리합니다.

- `data/kb_bank_products.csv`
- `data/kb_securities_assets.csv`
- `data/sample_holdings.json`
- `data/product_sources.json`
- `data/tax_rules.yaml`

상품명과 금리를 화면이나 추천 로직에 직접 넣지 않습니다. 데이터 갱신 시 공식 KB 공개 정보와 상품설명서를 사람이 확인한 뒤 `effective_date`, `last_verified_at`, 출처를 함께 수정해야 합니다. 공식 사이트를 실시간으로 크롤링하는 코드는 포함하지 않습니다.

은행 금리 정보는 마지막 확인 후 30일까지 계산에 사용합니다. 31~90일은 경고와 함께 금리 계산에서 제외하며, 90일을 초과하면 신규 추천에서도 제외합니다. 증권 자산은 승인, 미성년자 거래 가능, 비레버리지, 비인버스, 90일 이내 검증 조건을 모두 통과해야 합니다.

## Provider 경계

`lib/providers.ts`에 다음 인터페이스가 있습니다.

- `ProductCatalogProvider`
- `BankAccountProvider`
- `SecuritiesAccountProvider`
- `ProductRateProvider`
- `ProductEligibilityProvider`
- `ProductLinkProvider`

MVP는 CSV와 Mock 계좌 구현체만 사용합니다. 미래 API Provider는 실제 endpoint, 인증, 요청·응답 형태를 임의로 만들지 않고 `MVP 미연동` 오류와 TODO만 제공합니다. 모든 가입·거래 버튼은 `StaticProductLinkProvider`가 반환하는 Mock 이동이며 주문을 실행하지 않습니다.

## KB국민은행 기대효과

- 자녀 입출금통장 개설에서 끝나지 않고 예·적금, 펀드, 투자계좌의 장기 관리로 고객 관계를 확장
- 부모와 자녀가 함께 자산을 확인하는 금융교육 경험 제공
- KB스타뱅킹 내 자녀 관련 서비스의 지속적인 이용 유도
- 성장 단계에 따라 KB국민은행 상품과 KB증권 투자서비스를 자연스럽게 연결
- 예·적금 만기자금이 고객 목표에 적합한 KB 상품으로 재배분될 수 있도록 지원
- 단순 판매가 아닌 목표 기반 추천으로 상품 선택 근거 제공
- 자녀가 성년이 된 후에도 이어질 수 있는 장기 고객관계 형성

상품 판매보다 고객 적합성, 위험 수준, 투자기간과 장기 자산관리를 우선합니다. 적합하지 않은 상품을 추천하기 위해 성향이나 결과를 왜곡하지 않습니다.

## 한계와 주의

이 프로젝트는 공모전 데모입니다. 실제 로그인, 본인·법정대리인 확인, 계좌 개설, 금융자문, 세무신고, 주문 실행, KB 내부 API 또는 실제 딥링크를 제공하지 않습니다. 금리, 세금, 판매 여부와 거래 가능 여부는 바뀔 수 있으므로 실제 가입·거래 전 최신 상품설명서, 약관과 KB 채널의 안내를 확인해야 합니다.
